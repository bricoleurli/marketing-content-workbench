# 营销工作台界面改版验收

2026-11-03。本轮只修改独立应用的本地界面，未提交、推送或部署生产。

## 实际改动

- 新增 `static/workbench-theme.css`：自包含的浅竹青主题、系统中文字体、14px 正文、8px 控件圆角、白色内容面、绿色操作与选中态。主要操作至少 40px，删除和错误保留红色。原素材与预览画布不染色。
- `static/navigation.js`：外壳统一品牌、单一页名、说明和导航；保留五个页面实例，切换时只显示一个页面并暂停媒体、关闭弹层。设置可从任一页面打开，继续调用原配置 API。补齐 `.html` 直达路径的功能识别。
- `static/library.html`、`static/library.css`、`static/library.js`：移除宣传大标题、重复品牌和英文装饰。统计改为紧凑摘要，首屏直接呈现搜索、类型筛选、选择、导出和真实来源的素材。补上筛选按钮的选中语义。
- `static/topics.html`、`static/topics.css`、`static/topics.js`：分类收成紧凑筛选，长选题保持可读；同名分组筛选去重，去除重复序号，保留新建、文件导入、搜索和本机完成标记。
- `static/index.html`、`static/clips.html`、`static/overlays.html`、`static/styles.css`：移除旧深色皮肤和远程字体，统一内页工具栏、标题层级、详情字号和间距。窄屏使用整页滚动，配音历史继续可达。
- `static/overlays.js`：空模板禁用不可执行操作；渲染期间两个导出入口均禁用，完成或失败后恢复。九种模板的预览、拖拽、参数和渲染调用保持原实现。
- `static/app.js`：设置保存后刷新配音配置，保留正在编辑的文案。新增 `PRODUCT.md` 和 `DESIGN.md` 记录本次已确定的产品与界面约束。

后端、渲染器、部署配置、数据目录规则和公网限制均未修改。未引入旧 Studio、快速拼接或 Whisper。没有灵凌岛运行依赖，也未修改灵凌岛代码。
